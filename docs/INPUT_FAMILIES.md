# 输入分布族说明（input families）

生成器在 `core/inputgen.py`，全部是**确定性**函数 `(n, seed, params) -> float32[]`：
同一个 seed 一定生成同样的数据，因此 golden 可复现。矩阵 A、B 用同一族、不同 seed。

热力图（如 `results/_campaign/figs/heatmap_015_...`）的**行 = 输入分布族**；下面是
015 用到的 8 族，附“真实生成的示例值”（seed=1234）。

## 015 使用的 8 类

| 族 | 生成规则 | 示例值（前 8 个） | 直观含义 | 在 SDC 实验中代表什么 |
|---|---|---|---|---|
| `uniform` | `U(-1, 1)` | `0.933, -0.119, -0.985, 0.822, ...` | 值域中等、符号随机、无结构 | **对照基线**（control） |
| `normal` | 正态 `N(0,1)` | `1.05, -0.226, 2.20, 0.103, ...` | 典型真实数据；多数小、偶有较大值 | “常规”输入 |
| `sparse` | 90% 为 0，其余 `N(0,1)` | `-0.114, 0.0446, -1.30, 0, 0, 0, 0, 0` | 大量零 | 考察**掩盖(masking)**：0 参与的乘/加常把位翻转“吞掉” |
| `correlated` | 周期 64 的基向量 + 1% 噪声 | `0.938, -0.129, -0.983, ...`（每 64 个重复一个模式） | 元素高度相关（低秩/周期） | 代表**低秩矩阵**，考察结构对传播的影响 |
| `ones` | 全 1.0 | `1, 1, 1, 1, ...` | 所有元素相同、无多样性 | 误差不会被“不同数值”平均掉；乘积/和都精确 |
| `near_zero` | `±~1e-30`（10% 为 0） | `1.44e-30, -1.94e-30, 0, ...` | 极小量级；乘积下溢为 0（golden 输出≈0） | 考察**接近下溢/极小指数**时位翻转的暴露程度 |
| `near_overflow` | 99% `N(0,1)` + 1% 接近 `FLT_MAX` | 多数小值；偶见 `3.37e+38` | 少数接近上溢 | 考察**接近上溢**导致的 Inf 主导损坏（golden 可能出现 Inf） |
| `extreme` | 50% 接近 `±FLT_MAX` + 50% 小值 | `-0.114, 0.0446, -1.30, 2.74e+38, 2.78e+38, ...` | 大数小数混杂、动态范围极大 | 单比特翻转被**指数级放大**，最坏情况 |

各族的实测统计（seed=1234，N=262144）：

| 族 | 最大绝对值 | 最小非零绝对值 | 零占比 |
|---|---|---|---|
| uniform | 1 | 3.0e-06 | 0.00 |
| normal | 4.58 | 8.3e-06 | 0.00 |
| sparse | 4.07 | 5.1e-05 | **0.90** |
| correlated | 1.03 | 7.3e-07 | 0.00 |
| ones | 1 | 1 | 0.00 |
| near_zero | 2.0e-30 | 1.0e-30 | 0.10 |
| near_overflow | **3.37e+38** | 9.6e-06 | 0.00 |
| extreme | **3.06e+38** | 2.8e-05 | 0.00 |

## 其它可用族（008/016 等使用）

| 族 | 含义 |
|---|---|
| `lognormal` | 对数正态，宽动态范围（指数敏感） |
| `cancellation` | 大正负项相消，相对误差被放大 |
| `adversarial` | 极端指数摆动 + 抵消（工程化最坏情况） |
| `near_one` | 聚集在 1.0 附近（尾数舍入敏感） |
| `small` / `large` | 均匀分布在小/大区间 |
| `real` | 从磁盘读取真实张量 |

## 为什么这样划分

每族都对准一种**错误传播机制**（动态范围/指数、掩盖、抵消、低秩、上溢/下溢），
并且都能映射到 `scripts/features.py` 里的**可解释特征**（`log2_range`、`zero_frac`、
`exp_mean/exp_std`、`cancellation`、`near_overflow_frac`、`sign_flip_frac` 等）。
这样才能既做机制分析，又能训练“输入特征 → SDC 风险”的预测模型。

## 读热力图时的直观对照

- `near_zero` 行：误差普遍极小（下溢），说明“量级太小，翻位基本无害”。
- `near_overflow` / `extreme` 行：误差可达 `1e37+` 甚至被 Inf 主导（图中标 `n/a`），
  说明“接近溢出时，翻位后果最严重”。
- `sparse` 行：SDC 率相对更低，说明大量零提供了**掩盖**。
- `uniform` 行：作为其它族的**参照**（差值即该族输入的“额外影响”）。
